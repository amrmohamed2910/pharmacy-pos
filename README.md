# صيدليتي | Pharmacy Suite

نظام إدارة صيدليات متكامل بواجهة عربية وإنجليزية (RTL/LTR) وخادم FastAPI وقاعدة بيانات MySQL.

صُمم النظام ليكون سريعًا وواضحًا في الاستخدام اليومي: بيع بنقرة، إدارة مخزون دقيقة بنظام FEFO، مشتريات وموردون، تقارير ورسوم بيانية، وإدارة مستخدمين وصلاحيات.

---

## المزايا الرئيسية

- **لوحة تحكم** بإيرادات اليوم، الأرباح، الفواتير، التنبيهات والمخططات.
- **نقطة بيع (POS)** مع بحث فوري، باركود، إضافة سريعة، دفع كاش/شبكة/آجل، وطباعة إيصال.
- **مخزون ذكي** بتتبع التشغيلات (Batches) وتواريخ الانتهاء، وخصم تلقائي بنظام **FEFO** (الأقرب انتهاءً أولًا).
- **مشتريات وموردون** مع إنشاء فواتير شراء وتحديث المخزون تلقائيًا.
- **فواتير المبيعات** مع التفاصيل والإرجاع وإعادة الكميات للمخزون.
- **تقارير** مبيعات ومخزون مع رسوم بيانية وتصدير Excel.
- **إعدادات** بيانات الصيدلية، المستخدمون والصلاحيات، تغيير كلمة المرور.
- **واجهة ثنائية اللغة** عربي/إنجليزي مع تبديل فوري للاتجاه (RTL/LTR) وحفظ اللغة المختارة.
- **وضع ليلي** وتصميم متجاوب بهوية طبية هادئة.
- **أمان**: JWT، كلمات مرور مشفرة bcrypt، وصلاحيات حسب الدور (مدير/صيدلي/كاشير).

## التشغيل السريع (Windows)

1. تأكد أن خدمة MySQL تعمل على المنفذ `3306`.
2. شغّل ملف **`setup.bat`** مرة واحدة لتثبيت الحزم، إنشاء قاعدة البيانات، وبناء الواجهة.
3. شغّل ملف **`start.bat`** لتشغيل النظام وفتح المتصفح على:
   <http://127.0.0.1:8000>

### بيانات الدخول الافتراضية

| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `admin` | `admin123` | مدير النظام |
| `huda` | `huda123` | صيدلي |
| `mohamed` | `mohamed123` | كاشير |

> **مهم:** غيّر كلمة مرور `admin` من صفحة الإعدادات بعد أول دخول، وفعّل `JWT_SECRET` خاصًا بك في ملف `backend/.env`.

## التشغيل اليدوي

### 1) الخادم (Backend)

```powershell
cd D:\Pharmacy\backend
python -m pip install -r requirements.txt
python init_db.py        # إنشاء قاعدة البيانات إن لم تكن موجودة
python migrate.py        # ترقية الجداول الحالية دون فقدان البيانات
python seed_demo.py      # بيانات تجريبية (اختياري، لا يكرر نفسه)
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

- توثيق الواجهة البرمجية: <http://127.0.0.1:8000/docs>
- فحص الحالة: <http://127.0.0.1:8000/api/health>

### 2) الواجهة (Frontend)

```powershell
cd D:\Pharmacy\frontend
npm.cmd install
npm.cmd run build        # ينتج مجلد dist ويخدمه FastAPI تلقائيًا
```

### 3) وضع التطوير

شغّل الخادم والواجهة معًا:

```powershell
.\dev.bat
```

- الواجهة: <http://127.0.0.1:5173>
- الخادم: <http://127.0.0.1:8000>

> وضع التطوير يستخدم Vite مع وكيل (Proxy) يوجّه طلبات `/api` إلى الخادم.

## الإعدادات

يمكن تجاوز أي إعداد عبر متغيرات البيئة أو ملف `backend/.env` (انسخ `backend/.env.example`).

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `DATABASE_URL` | `mysql+pymysql://root:@127.0.0.1:3306/pharmacy_db?charset=utf8mb4` | رابط الاتصال بقاعدة البيانات |
| `JWT_SECRET` | قيمة تجريبية | مفتاح توقيع الرموز — **غيّره في الإنتاج** |
| `TOKEN_EXPIRE_MINUTES` | `720` | مدة صلاحية جلسة الدخول |
| `CORS_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173` | المصادر المسموح لها بالاتصال |
| `LOW_STOCK_THRESHOLD` | `10` | حد التنبيه لانخفاض المخزون |
| `EXPIRY_WARNING_DAYS` | `90` | عدد الأيام لتنبيه قرب الانتهاء |
| `DEFAULT_CURRENCY` | `ج.م` | العملة المعروضة |
| `DATABASE_SSL_CA` | فارغ | مسار شهادة CA لقاعدة بيانات سحابية مثل Aiven |
| `DATABASE_SSL_VERIFY` | `true` | التحقق من شهادة الخادم (اجعلها `false` للاتصال المشفّر بدون تحقق) |

## النشر على GitHub وRender مع قاعدة بيانات Aiven

المشروع يُنشر كخدمة واحدة: FastAPI يبني واجهة React تلقائيًا ويخدمها من نفس النطاق، ويتصل بقاعدة MySQL المستضافة على Aiven.

### 1) رفع الكود على GitHub

```powershell
cd D:\Pharmacy
git add .
git commit -m "Deploy: Render blueprint and Aiven SSL support"
git push origin main
```

المستودع الحالي: <https://github.com/amrmohamed2910/pharmacy-pos>

> ملف `render.yaml` في جذر المشروع يصف الخدمة كاملة، و`render.yaml` لا يحتوي أي كلمات مرور.

### 2) تجهيز قاعدة بيانات Aiven

1. من لوحة Aiven افتح خدمة MySQL ثم **Overview > Connection information**.
2. أنشئ قاعدة بيانات باسم `pharmacy_db` (أو استخدم `defaultdb`):
   ```sql
   CREATE DATABASE pharmacy_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
3. حوّل رابط الخدمة إلى صيغة SQLAlchemy:
   ```
   mysql+pymysql://avnadmin:PASSWORD@HOST:PORT/pharmacy_db?charset=utf8mb4
   ```
   - استخدم `%40` بدل `@` وأي رموز خاصة أخرى داخل كلمة المرور.
   - الجداول تُنشأ تلقائيًا عند أول تشغيل، ويُنشأ حساب `admin / admin123` إن لم يوجد.

### 3) النشر على Render

1. من <https://dashboard.render.com> اختر **New > Blueprint** واربط مستودع GitHub.
2. سيقرأ Render ملف `render.yaml` ويطلب قيمة `DATABASE_URL` — الصق رابط Aiven أعلاه.
3. اضغط **Apply**. بعد انتهاء البناء سيكون الرابط:
   `https://pharmacy-suite.onrender.com` (أو الاسم المتاح).
4. اختياري للأمان: من **Environment** أضف Secret File باسم `aiven-ca.pem` (ملف CA من لوحة Aiven)، ثم غيّر:
   ```
   DATABASE_SSL_CA=/etc/secrets/aiven-ca.pem
   DATABASE_SSL_VERIFY=true
   ```

### 4) بعد أول نشر

- افتح الرابط وسجّل الدخول بـ `admin / admin123`، ثم غيّر كلمة المرور فورًا من الإعدادات.
- `JWT_SECRET` يُولَّد تلقائيًا لكل خدمة على Render.
- الخطة المجانية على Render تُوقف الخدمة بعد 15 دقيقة خمول وتعيد تشغيلها عند أول طلب (قد يستغرق ~30 ثانية).
- لأي دومين مخصص: أضفه من Render ثم أضف رابطه إلى `CORS_ORIGINS` (اختياري لأن الواجهة والـ API على نفس النطاق).

## اللغة والاتجاه

- زر اللغة في الشريط العلوي (وفي صفحة الدخول) يبدّل الواجهة بين **العربية** و**English** فورًا، مع تحويل الاتجاه بين `RTL` و`LTR`.
- اللغة المختارة تُحفظ في `localStorage` تحت المفتاح `pharmacy-language`، ويُطبَّق الاتجاه قبل تحميل التطبيق لتجنّب وميض الاتجاه الخاطئ.
- اللغة الافتراضية عربية، وكل النصوص الإدارية (الأزرار، الجداول، النوافذ، رسائل الأخطاء والتنبيهات) مترجمة.
- تصدير Excel من صفحة التقارير يتبع اللغة الحالية: عناوين وأعمدة إنجليزية مع ورقة باتجاه LTR في الوضع الإنجليزي.
- أسماء الأدوية والتصنيفات وبيانات الصيدلية (الاسم، العنوان، تذييل الفاتورة، العملة) تُعرض كما هي مخزّنة في قاعدة البيانات ولا تُترجم.
- لإضافة ترجمة نص جديد: أضف النص العربي كمفتاح في الملف المناسب داخل `frontend/src/i18n/pages/` أو `common.js`، ثم استخدمه في الواجهة عبر `const { t } = useI18n(); ... {t("النص العربي")}`.
- عند إضافة متغيّر داخل النص استخدم `{var}` في المفتاح والقيمة: `t("تم حفظ {count} صنف", { count })`.

## التقارير والتصدير

- تقرير المبيعات: إيراد، خصومات، تكلفة، ربح، عدد فواتير، ومتوسط فاتورة.
- تقرير المخزون: قيمة المخزون بسعر التكلفة والبيع، الكميات، المنتهي وقارب الانتهاء.
- تصدير Excel مباشر من صفحة التقارير.

أرقام التقارير تُحسب من قاعدة البيانات مباشرة، وتشمل الفواتير المكتملة فقط (تُستثنى المرتجعة).

```powershell

```

```powershell
mysql -u root -p pharmacy_db < pharmacy_backup.sql
```
